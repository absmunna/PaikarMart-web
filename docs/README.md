# PaikarMart System Documentation

This directory contains the central architectural and technical documentation for the PaikarMart platform.

## 📁 Directory Structure
- **`architecture/`**: High-level system architecture, client vault specifications, admin security guidelines, and design systems.
- **`api/`**: REST API endpoints, DTO contracts, authentication flow, and backend interfaces.
- **`database/`**: Database schemas (PostgreSQL / Supabase / Prisma), migrations, and entity relation mapping.
- **`roles/`**: Role-based access control (RBAC), multi-role capabilities, and authentication verification rules.
- **`plans/`**: System master plan, ecosystem roadmaps, and hub specifications.
- **`audits/`**: Security audits, system architecture reviews, and performance evaluations.
- **`updates/`**: Component, portal, and feature update logs and changelogs.
- **`governance/`**: Platform rules, compliance policies, dispute resolution, and regulatory constraints.
